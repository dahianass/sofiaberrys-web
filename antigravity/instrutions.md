# Objetivo del proyecto

Crear una aplicación de venta de fresas y flores llamada 
"Sofias Berrys", usando NextJS (App Router) y Tailwind.

El objetivo es implementar el diseño y las funcionalidades básicas de una app de venta de fresas y flores moderna, en el catalogo hay una opción que se llama personalizar, allí se podra selecionar diferentes tipos de arreglos de fresas con flores, si el usuario lo desea, este modulo se encuentra en la pagina de "PERSONALIZAR" que se encuentra en el menu de navegacion, allí esta se compartara como un juego donde abra una imagen base de una frase y se le adicionara los elementos segun lo selecionados en los pasos 1,2,3 y 4 incluyendo empaquetado y las flores que te gustaría adicionar, con un estilo minimalista, siguiendo exactamente los diseños presentados en las referencias que serán proporcionadas que se encuentran en la carpeta de "Antigravity" dentro del proyecto.
